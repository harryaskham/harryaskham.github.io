  Title was either `(N) Cacophony Dashboard` or plain
  `Cacophony Dashboard`. Multiple dashboard tabs (a common

  state.currentView for dynamic sub-views, and renders as
  `{badge}{view} · Cacophony Dashboard`. The default `status`
  landing keeps a plain `Cacophony Dashboard` title to avoid
  noise on fresh opens.

  schedules `setTimeout(() => updateDocumentTitle(), 0)` (app.js
  line ~1284) after setting state.currentView.
- Tab text leftmost = most distinguishing info: most browsers
  truncate tab text from the right when many tabs are open, so
  putting the view name first means it survives narrow tabs.
