Validation evidence for bd-874f33:

- Before: 2 of 14 text-input Enter handlers in the dashboard
  were missing the bd-34d83f IME composition guard:
    - #agent-nudge-input (Enter sends message to agent)
    - #agent-tty-search  (Enter runs terminal search)
  IME users (JP/CN/KR/VN etc.) pressing Enter to commit

  the full guard:
