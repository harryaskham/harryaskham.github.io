Validation evidence for bd-8fb2c0:

- Before: /app.js is 575 KiB, the largest dashboard asset, loaded
  with <script defer> at index.html line 1089. With only `defer`,
  the browser discovers /app.js after parsing ~1063 preceding HTML
  lines (body chrome, sidebar nav, every workspace shell, 5 modal
  templates).
- After: a `<link rel="preload" as="script" href="/app.js">` hint
  in <head> (placed AFTER all stylesheet links so CSS still wins
  priority) lets the browser start the fetch as soon as the head
  is parsed (~line 30) instead of waiting until line 1089. On
  cold-cache and slow connections this saves measurable LCP/TTI;
  once the <script defer> tag is reached the response is already
  in flight or cached -- no double fetch.

  bd-07121d defensive "no inline <script>" guard. Reworded the
  comment to avoid the bare token; both bd-8fb2c0 and bd-07121d
  pass.
