Validation evidence for bd-916b85:

- Before: 2 setInterval callbacks in app.js fired even when the
  tab was hidden:
    L8565 TTY polling fallback (1s, payload up to 200 KB/tick)
       = 60 req/min, up to 12 MB/min on a hidden tab
    L7151 TTS status refresh (10s) = 6 req/min
  Combined: 66 req/min wasted on idle hidden tabs.

- After: each callback short-circuits on visibilityState !== 'visible'.
  TTY polling additionally registers a visibilitychange listener (stored
  on ttyState._vizListener) that fires one immediate tick() on tab return
  so the terminal buffer is fresh the moment the operator looks.
  teardownAgentTty removes the listener to avoid leaking across agent
  switches. TTS interval already self-clears when navigating away from
  services view, so no return-handler needed.

- Direct foreground validation (per revival nudge; not queued/backgrounded):

      -> 1 passed, 0 failed

         failures on main).
