    fi.style.color = ''

- state.lastFreshnessSig referenced (state-bag scoped,
  survives across snapshots).
- Signature combines class+text/html+title via concat
  per bd-5e0030.
- DOM mutations gated behind `if (state.lastFreshness-
  Sig !== sig)` block (signature includes
  state.lastFreshnessSig=sig assignment + classList
  remove/add + style.color + innerHTML).

  (per bd-57c0f5 pattern).
