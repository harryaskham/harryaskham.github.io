Validation evidence for bd-873a66:

- Before: 66+ surfaces in style.css declared backdrop-
  filter: blur(...) for the glass aesthetic; users
  with macOS "Reduce Transparency" / Windows equivalent
  saw legibility-degrading heavy blur with no
  accommodation. The codebase honoured 3 sibling a11y
  preferences (prefers-reduced-motion x32, prefers-
  contrast: more, :focus-visible) but missed this 4th.
- After: workspace-a11y.css declares a @media (prefers-
  reduced-transparency: reduce) block that universally
  strips backdrop-filter and -webkit-backdrop-filter
  (covering *, *::before, *::after) and forces 10
  common glass surface classes onto opaque var(--bg-
  secondary) backgrounds.
- Browser support: Chrome 118+, Safari 17.4+, Firefox
  113+. Older browsers fall through to existing glass.

- Direct foreground validation (per revival nudge; not queued/backgrounded):
    cargo test -p caco-web --lib prefers_reduced_transparency_block_strips_backdrop_blur_bd_873a66
      -> 1 passed, 0 failed
    cargo test -p caco-web --lib --tests
      -> 487 passed, 11 failed (net +1 pass; same 11 pre-existing
         failures on main).
- Whitespace: git diff --check origin/main..HEAD -> clean.

Test design (6 layers):
- Brace-depth block scoping isolates the @media body.
- Universal-strip declaration covers both standard and
  -webkit-prefixed properties.
- Selector chain includes *::before/*::after for glass
  overlay pseudos.
- 5 common glass surface classes pinned.
- Sibling-presence pin for @media (prefers-contrast: more).
- Cross-stylesheet count layer for prefers-reduced-motion
  (>=30 across 13 stylesheets) so the broader a11y
  preference family isn't accidentally regressed.
