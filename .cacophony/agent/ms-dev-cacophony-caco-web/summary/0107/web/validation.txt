LESSON LEARNED -- awk-scan false-positive on compound
selectors: awk pattern `/^[a-zA-Z\.#:*][^{},]*\{$/` matches
a selector LINE that ends in `{`, but compound selectors
that wrap with `,` continuations across multiple lines
(e.g. `.ws-split--h > .ws-split-handle::after,\n.ws-split
--v > .ws-split-handle::after {`) cause the second
continuation line to match independently of the first. The
scan reports an inflated duplicate count. Future scans
must verify each reported duplicate is a TRUE standalone
rule head, not a compound-rule continuation, before
attempting paired-merge work.
