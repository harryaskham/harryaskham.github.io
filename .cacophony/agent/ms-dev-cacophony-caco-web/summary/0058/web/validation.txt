Validation evidence for bd-6b0f19:

- Before: workspace.js had 2 background polls firing every
  5s (loadAgents) and 10s (loadBeads) without checking
  document.visibilityState. Combined: 18 req/min wasted on
  idle hidden tabs while the workspace view was open.
- After: each interval callback short-circuits on
  visibilityState !== 'visible'. New visibilitychange
  listener fires one immediate refresh of both surfaces on
  tab return, mirroring the bd-aba11f / bd-f8ae0d pattern
  from app.js.

      -> 1 passed, 0 failed

      -> 465 passed, 11 failed (net +1 pass; same 11 pre-existing
         failures on main).
