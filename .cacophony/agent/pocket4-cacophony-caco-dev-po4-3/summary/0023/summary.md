# Session Summary — bd-0d9db5 (Add tts.lang configuration support)

## Bead
**bd-0d9db5** (P2 feature, labels: config, language, tts)
"Add tts.lang configuration support"

Foundational config slice. Two dependent beads (documenting + surfacing `tts.lang` in
the UI) were linked blocked-on-this by po4-1 rather than claimed prematurely.

## What was implemented
A `speech.tts.lang` configuration option: an ordered list of language codes whose first
entry is the default synthesis language, falling back to `en-US`, with the resolved
default persisted in TTS daemon runtime state so it survives daemon restarts for session
resumption alongside the active voice and speed.

## Changes
### Config model (`crates/caco-config/src/model.rs`)
- `TtsConfig.lang: Option<Vec<String>>` — ordered preferred language codes.
- `TtsConfig::DEFAULT_LANG = "en-US"`.
- `TtsConfig::default_lang(&self) -> String` and shared
  `TtsConfig::resolve_default_lang(Option<&[String]>) -> String` — first non-blank entry
  (whitespace-trimmed), else `en-US`. Shared resolver so runtime seeding applies identical
  semantics.
- `impl Default for TtsConfig` + `SpeechConfig` node/global merge updated to carry `lang`
  (node-level list wins over global).

### TTS daemon runtime + persistence (`crates/caco-cli/src/tts_daemon.rs`)
- `TtsDaemonRuntimeState.lang: String`.
- Config resolution: `tts_lang = resolve_default_lang(service_tts.lang OR effective
  speech.tts.lang)`, threaded into `tts_daemon_loop(..., lang, ...)`.
- `initial_lang`: persisted lang wins (session resumption), else config-resolved default.
- `persist_tts_daemon_state` saves `lang`; restore log line includes it.

### Persisted state (`crates/caco-tui/src/speech.rs`)
- `TtsDaemonPersistedState.lang: Option<String>` (serde default, skip-if-none).

### Test-literal + README upkeep
- Added `lang` to all exhaustive `TtsConfig` / `TtsDaemonRuntimeState` /
  `TtsDaemonPersistedState` literals across validate.rs, tests/config.rs, caco-daemon
  audio.rs, caco-tui (speech.rs, state/tests.rs), and caco-cli lib.rs tests (anchored on
  the TtsConfig-unique `speed:`→`voice_filter:` / persisted `speed:`→`filter_enabled:`
  field adjacency; one false-positive insertion into `ResolvedTtsPersona` was reverted).
- README `speech.tts` settings sentence now lists `lang` with its semantics.
